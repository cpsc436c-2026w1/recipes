== 2. A role for the function. The trust policy says who may use it: the Lambda service

$ aws iam create-role --role-name recipe-api-role --tags Key=purpose,Value=recipe --assume-role-policy-document {"Version":"2012-10-17","Statement":[{"Effect":"Allow",
    "Principal":{"Service":"lambda.amazonaws.com"},"Action":"sts:AssumeRole"}]} --query Role.Arn
"arn:aws:iam::111122223333:role/recipe-api-role"

== 3. What the role may do: read and update the three tables, and write its own logs. Nothing else

$ aws iam put-role-policy --role-name recipe-api-role --policy-name tables-and-logs --policy-document {"Version":"2012-10-17","Statement":[
  {"Sid":"TripsAndDrivers","Effect":"Allow",
   "Action":["dynamodb:GetItem","dynamodb:Query","dynamodb:UpdateItem"],
   "Resource":["arn:aws:dynamodb:ca-central-1:111122223333:table/recipe-trips","arn:aws:dynamodb:ca-central-1:111122223333:table/recipe-rider-trips","arn:aws:dynamodb:ca-central-1:111122223333:table/recipe-drivers"]},
  {"Sid":"OwnLogs","Effect":"Allow",
   "Action":["logs:CreateLogGroup","logs:CreateLogStream","logs:PutLogEvents"],
   "Resource":"arn:aws:logs:ca-central-1:111122223333:log-group:/aws/lambda/recipe-api:*"}]}

== 4. The function's log group, kept 7 days; then package and create the function: Python 3.12 on arm64, 128 MB, 10 s timeout (boto3 is in the runtime already)

$ aws logs create-log-group --log-group-name /aws/lambda/recipe-api --tags purpose=recipe

$ aws logs put-retention-policy --log-group-name /aws/lambda/recipe-api --retention-in-days 7

$ python3 -c import zipfile,sys; z=zipfile.ZipFile(sys.argv[1],'w'); z.write(sys.argv[2],'handler.py'); z.close() /tmp/recipe-api.zip lambda-dynamodb/main/handler.py

$ aws lambda create-function --function-name recipe-api --runtime python3.12 --architectures arm64 --memory-size 128 --timeout 10 --handler handler.lambda_handler --role arn:aws:iam::111122223333:role/recipe-api-role --zip-file fileb:///tmp/recipe-api.zip --environment Variables={PREFIX=recipe} --tags purpose=recipe --query {name: FunctionName, runtime: Runtime, arch: Architectures[0], memory_mb: MemorySize, state: State}
{
    "name": "recipe-api",
    "runtime": "python3.12",
    "arch": "arm64",
    "memory_mb": 128,
    "state": "Pending"
}

$ aws lambda wait function-active-v2 --function-name recipe-api

== 5. Call it directly once, with an event (the way another AWS service would call it)

$ aws lambda invoke --function-name recipe-api --cli-binary-format raw-in-base64-out --payload {"action":"get","trip_id":"t-0042","strong":true} /tmp/recipe-api-out.json --query {status: StatusCode, error: FunctionError}

== 6. A public HTTPS address: a function URL with auth type NONE. Anyone who has the URL can call it

$ aws lambda create-function-url-config --function-name recipe-api --auth-type NONE --query {url: FunctionUrl, auth: AuthType}
{
    "url": "https://<url-id>.lambda-url.ca-central-1.on.aws/",
    "auth": "NONE"
}

== 7. A public URL needs two statements in the function's resource policy: invoke through the URL, and invoke at all only via the URL

$ aws lambda add-permission --function-name recipe-api --statement-id url-public --action lambda:InvokeFunctionUrl --principal * --function-url-auth-type NONE --query Statement --output text
{"Sid":"url-public","Effect":"Allow","Principal":"*","Action":"lambda:InvokeFunctionUrl","Resource":"arn:aws:lambda:ca-central-1:111122223333:function:recipe-api","Condition":{"StringEquals":{"lambda:FunctionUrlAuthType":"NONE"}}}

$ aws lambda add-permission --function-name recipe-api --statement-id url-invoke --action lambda:InvokeFunction --principal * --invoked-via-function-url --query Statement --output text
{"Sid":"url-invoke","Effect":"Allow","Principal":"*","Action":"lambda:InvokeFunction","Resource":"arn:aws:lambda:ca-central-1:111122223333:function:recipe-api","Condition":{"Bool":{"lambda:InvokedViaFunctionUrl":"true"}}}
